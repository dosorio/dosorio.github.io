Summary

I'm a Colombian computational biologist who builds methods and software that turn single-cell and multi-omics data into biological and therapeutic insight. My work spans gene regulatory network inference (scTenifoldNet, SCORPION), in-silico perturbation (scTenifoldKnk), and drug discovery, spanning disease-specific drug response signatures (retriever) and drug combination prediction for cancer. I'm a Senior Scientific Consultant at QIAGEN Digital Insights, working with pharma and biotech teams.

Software Packages

pySCORPION
Code | Paper | Released 2026

Brings SCORPION's sample-level gene regulatory network reconstruction to Python workflows.

SCORPION
Code | Paper | Released 2022

Builds comparable, sample-level gene regulatory networks from single-cell data for population-scale comparisons.

retriever
Code | Paper | Released 2021

Distills LINCS-L1000 drug responses into disease-specific signatures, independent of cell line, dose and time.

rPanglaoDB
Code | Paper | Released 2021

Downloads and merges cell-type-labeled single-cell RNA-seq data from PanglaoDB.

scTenifoldKnk
Code | Paper | Released 2020

Runs virtual gene knockouts on wild-type single-cell data to predict gene function.

scTenifoldNet
Code | Paper | Released 2019

Builds and compares single-cell gene regulatory networks across conditions to pinpoint rewired genes.

exp2flux Archived on CRAN
Code | Released 2016

Turns gene expression into flux balance analysis bounds using each reaction's gene-protein-reaction rules.

g2f Archived on CRAN
Code | Paper | Released 2016

Finds and fills gaps in metabolic reconstructions using weighted reactions from a reference network.

minval Archived on CRAN
Code | Paper | Released 2016

Validates stoichiometric reactions: flags orphan metabolites and checks mass and charge balance.

Peptides
Code | Paper | Released 2014

Computes physicochemical properties and indices from peptide and protein sequences.
